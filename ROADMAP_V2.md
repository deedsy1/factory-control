## Roadmap V2

### V2.1 — Operate 20–200 sites without pain
- Fleet controls: tags + bulk select + bulk actions (run/pause/push/hide)
- Per-site state: paused/frozen + notes + owners
- Coverage: target pages / done / remaining / % complete

### V2.2 — Contracts + rollouts you can trust
- Versioned prompt contracts: core/prompts.yaml → pick version per site
- Versioned gate/filter contracts: push to selected sites
- Dry-run summary before enqueue

### V2.3 — Monetization automation
- Ads rules engine (auto-enable + manual override)
- Monetization readiness badge in UI

### V2.4 — Unattended reliability
- Failure buckets + retry-all
- Schedule presets (weekly growth / nightly retry / monthly refresh)
- Global kill switch + rate limit guardrails

### V2.5 — Factory becomes a real website creator
- Idea → Site wizard: niche → site skeleton + page list + contracts → bootstrap + queue
